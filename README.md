# liftyaml

Lift digests and yaml fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/liftyaml/

## Install / run

```bash
git clone https://github.com/theworker02/liftyaml.git
cd liftyaml
node src/cli.js
node --test
```
